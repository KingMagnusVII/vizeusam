# My Schedule Buddy

A personal timetable and productivity web app designed to make managing classes, tasks, and friends' schedules simple on both desktop and mobile.

**Live app:** https://vizeusam.lovable.app

## ✨ Features

- 📅 **Weekly timetable** — Navigate between days and view classes in a clear schedule.
- 👤 **Personal timetable** — Keep your own classes organized in one place.
- 👥 **Friends' timetables** — Add and switch between friends' schedules without leaving the app.
- 📝 **Class details** — Track the class name, professor, time, location, and tasks associated with a class.
- ✅ **To-do list** — Keep tasks separate from the timetable while still having them available alongside your schedule.
- 📥 **Timetable import** — Import timetable data from formats such as CSV/JSON to update schedules more easily.
- ✏️ **Timetable editing** — Add, edit, and delete classes and timetable data.
- 🎨 **Customization** — Change themes and personalize the appearance, including wallpaper/background options.
- 📱 **Responsive UI** — Designed to work across desktop and mobile screens.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm

### Installation

```bash
git clone https://github.com/KingMagnusVII/vizeusam.git
cd vizeusam
npm install
```

### Development

```bash
npm run dev
```

The development server will start locally and provide a URL to open in your browser.

### Production build

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```

### Code quality

```bash
npm run lint
npm run format
```
